## 2. Official domains and weights

| Domain | Weight |
|---|---|
| Data Management | 32% |
| Visualization | 25% |
| Analysis and Geoprocessing | 25% |
| Layouts and Sharing | 18% |

### Official objectives
**Data Management (32%)**
1. Manage geospatial data (raster, vector, tabular).
2. Manage coordinate systems to preserve the desired spatial properties.
3. Given a scenario, determine the appropriate existing geodatabase elements to use.
4. Use ArcGIS Pro editing functionality to create, modify, and delete features and attributes.

**Visualization (25%)**
1. Identify how to control the coordinate system and geographic transformation in ArcGIS Pro.
2. Manage layer properties using the ribbon and dialog boxes.
3. Determine how to visualize temporal, ranged, or 3D data.
4. Given a scenario, apply a query.

**Analysis and Geoprocessing (25%)**
1. Compare table joins and relates, relationship classes, and spatial joins.
2. Given a scenario, determine the appropriate geoprocessing tool.
3. Given a scenario, use tasks, batch processing, models, or scripts for a complex workflow.
4. Apply raster functions for raster and image processing.

**Layouts and Sharing (18%)**
1. Identify how to export data, maps, and scenes to different formats.
2. Choose how to share content from ArcGIS Pro.
3. Determine how to create and manage map layouts and map series.

### Candidate task list (official, abridged)
Compare geographic data types; convert formats; manipulate projections and transformations; map visualization; local/global raster functions; build maps from datasets and services; layer properties and tables; author SQL/Python/Arcade/VBScript expressions; time-enabled data; editing; sharing across ArcGIS; spatial analysis; geoprocessing environments; evaluate dataset suitability; use existing models/scripts/notebooks; create a model for a repeatable process; use Tasks.

### Officially out of scope
Database administration, ArcGIS Enterprise administration, authoring Tasks, troubleshooting computer/network systems, interpreting complex Python.

## 3. Corrections to the master prompt's planning targets
The master prompt's illustrative split (80/60/65/45) does not match the official weights, and the official Visualization/Layouts content differs from the suggested modules (it includes temporal/3D data, queries, geographic transformations, Tasks, and raster functions; Network Analyst is not listed). Label these in the UI as an educational allocation, not an exam distribution.
